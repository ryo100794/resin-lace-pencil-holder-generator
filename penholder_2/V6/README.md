# 象牙風多層球ペン立て V6

このフォルダーは `ryo100794/resin-lace-pencil-holder-generator` の `penholder_2/V6/` に保存するV6一式です。

V6は、ペン立て本体と9個の多層球に、造形方向に合わせた専用サポートを追加した版です。3層・4層・5層の球をそれぞれ3個配置し、元の回転層、対向する2点の軸受、内部支持81本を維持しています。

## 大きなファイルを復元する

この保存では、GitHub連携で転送できることを実際に確認した、1個8 MiB以下の`.part001`等を使います。利用した連携経路には64 MiBの転送フレーム上限があり、32 MiBの断片でも別の転送エラーになったため、大きな5ファイルをさらに小さく分割しています。GitHub本体の通常ファイル上限とは別の制約です。1 MiBは1,048,576 Bです。

リポジトリを取得した後、`penholder_2/V6/`で次を実行してください。Pythonの標準ライブラリだけを使います。

```sh
python verify_files.py
python restore_parts.py
```

`restore_parts.py`は`BINARY_PARTS.json`の順序で断片を結合し、各断片と完成ファイルのSHA-256を確認してから、元の3MFまたはZIPを同じフォルダーに確定します。元ファイルがすでに存在して内容が一致する場合はスキップし、異なる場合は上書きせず停止します。断片は元ファイルをバイト単位で分割したものであり、通常の分割ZIP形式ではありません。断片を直接スライサーや解凍ソフトへ渡さず、復元してから使ってください。

元ファイルを作成せずに、全断片と完成時のハッシュを検査する場合は次を実行します。

```sh
python restore_parts.py --verify
```

Google Driveには同一内容を単独ファイルでも保存しています。[完成3MF](https://drive.google.com/file/d/1eanVDmxAfp77GjXAtpRCAsn9ATcvXP52/view?usp=drivesdk)、[STL ZIP](https://drive.google.com/file/d/1TcpRv2xaz4NKMHNp2dAIKl010vd2sFL2/view?usp=drivesdk)、[V6フォルダー全体](https://drive.google.com/drive/folders/1rCi9XRJ2uz8qs0p4e8NGLYBGWCPK55T1)から取得できます。

## 印刷に使うファイル

`models/ivory_penholder_v6_custom_supported.3mf` を優先してください。STLを使う場合は `models/ivory_v6_stl.zip` を展開します。モデルの単位は mm、倍率は100 %、寸法は110.974 × 108.234 × 111.400 mmです。

モデル底面のZ=0をビルド面へ置き、モデル座標の+Z方向に造形してください。この向きに合わせて支持を組み込んでいるため、スライサーの自動サポート生成はOFFにします。回転・傾斜・縮小・底面の持ち上げを行うと、今回検査した支持条件が変わります。

## 再構築する手順

`ivory_v6_project.zip` と `ivory_v6_support_assets.zip` の両方を同じ親フォルダーへ展開し、`project/` の内容を合わせます。2本は分割バイナリではなく通常のZIPで、再構築には両方が必要です。`ivory_v6_repair_history.zip` は別の場所へ展開してください。

展開した `project/` で実行します。

```sh
python -m pip install -r source/requirements.txt
python source/rebuild_v6.py
```

画像も作成する場合は `python source/rebuild_v6.py --render` を使います。全高の接続検査にはC++17対応のg++、Linuxで画面なしの描画を行う場合はXvfbなどが必要です。標準の再構築は採用済みの支持部品を使い、保存した除去指示を初期候補として切断・移動・退出を再検証するため、計算に時間がかかります。

## 支持を除去する手順

造形プレートから外した後、今回追加した外部支持を先に処理します。`docs/REMOVE_ORDER_JA.txt` の順序に従い、正確なモデル座標は `docs/support_removal_index.json` を参照してください。外部支持の後に、最も内側の層間から順に既存の内部支持を外します。各層は配布モデルの初期姿勢を保ち、全支持を外してから個別に回転を確認してください。

プレビューのオレンジは今回の除去対象、青は残す小補強、象牙色は元のV5形状です。色は説明用であり、多材料の印刷指定ではありません。青い小補強、固定枠、軸、軸受は残します。

## 検証の範囲

閉じたメッシュ、面の向き、積層時の接続、回転範囲、内部支持への作業経路、外部支持1053件の取り出し、3MF/STLへの出力一致を幾何学的に検査しています。外部支持の取り出し検査で残った未解決操作は0件です。再構築用ZIP2本は、17519件の実ファイル、全12432件の除去検査入力、標準処理で必要な36ファイルのソース参照関係を含むことを確認済みです。

実際の樹脂強度、剥離荷重、収縮、刃の入り方、工具の柄や指の作業空間、切断力、印刷成功率は未検証です。過去に印刷した版・装置・樹脂・破損工程を確定したものでもありません。幾何学検査を、実機での印刷や強度の合格と同一視しないでください。

## Google Driveの保存先

[workspace/penholder_2/V6](https://drive.google.com/drive/folders/1rCi9XRJ2uz8qs0p4e8NGLYBGWCPK55T1) に同じ配布ファイルを保存しています。V2からV5の版フォルダーは維持されています。主要13ファイルは、Driveからの実ダウンロード後にサイズとSHA-256が元データと一致することを確認しています。

`SHA256SUMS.txt` は元の配布ファイル名を用いた凍結済み記録です。このフォルダーでは用途別のサブフォルダーへ配置しているため、GitHubへ保存する断片と通常ファイルのパス・サイズ・SHA-256・Gitのblob識別子は `FILE_MANIFEST.json` に記録しています。分割前の5ファイルのサイズとハッシュは `BINARY_PARTS.json` に残しています。`python verify_files.py` で展開済みのこのフォルダーを照合できます。マニフェスト自身は循環参照を避けるため台帳の対象外です。GitHub上への転送結果は、保存完了後に作成する別の記録で確認してください。

`reports/` には最終結果を読むための記録を抜き出しています。全98件の元の報告書と途中の修正履歴は、配布ZIPに変更せず収めています。
